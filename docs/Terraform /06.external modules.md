## 1-1. terraform registry
- 다양한 provider, module, policy 제공 
- [https://registry.terraform.io/](https://registry.terraform.io/)

## 1-2. 대표적인 AWS module
- [aws module](https://registry.terraform.io/namespaces/terraform-aws-modules)
- git을 통해서 source download 됨
    - ```tfg -type=plan | dot -Tsvg > graph.svg```
- 단점 : 
    1. `terraform graph` 에서 의존성 확인이 어려움 
    2. 외부 모듈을 한 번 사용한 이후에 변경이 쉽지 않음. 
        - 내부적으로 count 등으로 list 관리하는 경우 변경 시 자원 쟂생성이 일어남
        - customising 하기 위해서 mapping이 어려움
- _ex: VPC 생성_ 
    ```hcl
    module "default_vpc" {
        source = "terraform-aws-modules/vpc/aws" ## 외부 소스 : source location : external, github

        name = "default_vpc_${terraform.workspace}"
        cidr = "10.0.0.0/16"

        azs             = ["ap-northeast-2a", "ap-northeast-2b"]
        private_subnets = ["10.0.1.0/24", "10.0.2.0/24"]
        public_subnets  = ["10.0.101.0/24", "10.0.102.0/24"]

        # NAT gateway 는 미사용
        # enable_nat_gateway     = true
        # single_nat_gateway     = false
        # one_nat_gateway_per_az = true

        # igw 미사용
        create_igw = false

        # security group 추가
        manage_default_security_group = true

        tags = {
            Terraform   = "true"
            Environment = terraform.workspace
        }
    }

    resource "aws_instance" "web_instances" {
        count         = 2
        ami           = "ami-035233c9da2fabf52"
        instance_type = "t3.micro"

        subnet_id = module.default_vpc.public_subnets[count.index]

        tags = {
            Name = "web_inst_${count.index}"
        }
    }
    ```
