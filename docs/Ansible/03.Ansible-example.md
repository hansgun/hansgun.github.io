# 03. Ansible-example.md 

## 1. 실행 사례 
- on-prem에 작업할 때... terraform이 cloud는 더 편함 
    - IaaS 형태는 ansible 가능.. 
### 1-1. 파일 구조 
    ```bash
    ❯ tree .
    .
    ├── inventory.yml
    └── playbook.yml
    ```
### 1-2. 세부 내용
- `inventory.yml`
    ```yaml
    all:
        hosts:
            3.35.206.123: # aws ubuntu ec2 instance IP
        vars:
            ansible_user: "ubuntu" # user to connect
    ```
- `playbook.yml`
    ```yaml
    ### playbook.yml
    - name: nginx install and start 
        hosts: all
        gather_facts: true
        become: true

        tasks:
            - name: update
                apt: update_cache=yes
                run_once: true
            - name: Install Nginx
                apt: name=nginx state=latest
                notify:
                - restart nginx
            - name: init index page 
                get_url:
                    url: https://github.com/nginx/nginx/blob/master/docs/html/50x.html
                    dest: /usr/share/nginx/html/index.html mode 0644
                    # /usr/share/nginx/html 
                register: result_init_index
            - name: restart nginx
                service: name=nginx state=reloaded
                register: result_restart_nginx
      ```
- execution
    ```bash
    ## ssh-add .pem 
    $ ssh-add ~/.ssh/xxxx.pem 

    ## ansible 추가 
    $ ansible-playbook -i inventory.yml playbook.yml
    ```
