# 05.provisioner

# 1. 개요
- 로컬이나 서버에서 스크립트를 실행하는데 사용
- 종류
    - local-exec : 로컬에서 실행됨 
    - remote-exec : 타켓 머신에서 실행 
→ remote 의 경우 connection 설정이 필요하며 이 과정이 쉽지 않으며,특히 private 환경에서 proxy 설정 등이 까다로움 
→ docker 등 container 환경에서는 Dockerfile 로 해결 가능하므로 잘 사용하지 않음 
→ 같은 이유로 Puppet, Chef가 현재 잘 사용되지 않음
- ex)
    ```hcl
    resource "aws_eip" "eip_test" {
        provisioner "local-exec" { #### local-exec 설정
            command = "echo ${self.public_ip}"  #### self, public_ip : eip.IP 정보 출력
        }

        tags = {
            Name = "temp"
        }
    }
    ```
