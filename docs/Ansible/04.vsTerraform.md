# 04.Ansible vs Terraform Provisioner 

## 1. 언제 사용할까? 
- terraform 사용 중 → terraform provisioner 
- 하이브리드 클라우드 → ansible
- k8s 사용 환경이면 k8s provisioner : Rancher? vanilla? 

- ansible은 변수 사용하기가 쉽지 않음.. yaml 파일, terraform은 code level 에서 확인 가능 
- ansible은 서버 리스트화 하기 좋음 
    - 관리해야 할 서버가 많은 경우 편하다. 

## 2. 그래서..
- `vs code` 등 IDE를 활용할 때, 자동 완성 등 편리함은 extension으로 어느 정도 해결 가능 
- 많은 수의 서버 관리를 위하여 `ansible` 활용 가능하지만, 
- 기본적 인프라인 서버(가상환경 포함) 이외의 PaaS, SaaS 서비스엔 `terraform` 이 비교할 수 없을 만큼 편리하다. 
    - 관리형 cloud 서비스를 main으로 사용하는 환경에서는 `terrafor`을.. 
    - 서버에서 반복적인 작업을 주로 하거나 hybrid, on-prem이 main 인 환경에서는 `ansible` 이 좋은 선택지 인 것 같다.
